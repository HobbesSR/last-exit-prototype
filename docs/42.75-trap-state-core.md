# 42.75. Trap state in the Rust core (#1214 stage 6b)

Up: [42](42-performance-history.md). Design: [27](27-rust-path.md#the-state-flip), step 6b. `rust/core/src/hazards.rs`
keeps the game's traps between calls, and `shared/simulation/hazards.ts` uploads a trap list only when it is new,
replaced, a different length, or after `setTrap`. `characterization-physics`, its `-bots` variant and
`tools/trap-continuity.mjs` passed unchanged; the continuity trace matched pristine `main` (`15d1ff24`) hash for hash.

## Finding

**On a map with 277 traps the phase's crossing fell by about 19 µs a tick, from about 44 µs to about 25 µs. On the
bench's own map, which places no traps, nothing changed.**

| 24x12, seed 4217, median of five rounds | Current run 1 | Baseline (`15d1ff24`) | Current run 2 |
| --- | ---: | ---: | ---: |
| No traps: whole tick with snapshot | 4.868 ms | 4.966 ms | 4.683 ms |
| No traps: `sim.environment` | 16.94 µs | 17.11 µs | 16.91 µs |
| 277 traps: whole tick with snapshot | 5.128 ms | 5.090 ms | 5.111 ms |
| 277 traps: `sim.environment` | 54.12 µs | 72.32 µs | 51.90 µs |
| 277 traps: `sim.environment.core` | 28.84 µs | 28.65 µs | 27.88 µs |
| 277 traps: the label minus the core (conservative crossing) | 25.3 µs | 43.7 µs | 24.0 µs |

- **What went.** Ten words a trap, packed every call: about 2,770 words a tick on this map, plus a roster lookup for
  each trap's target. The core's own run is unchanged, as the rules are.
- **What still crosses** is the roster, the hazard areas and the trap content, as before, and each trap's writes coming
  back to the mirror. The writes are most of the remaining crossing with traps, since every live trap writes
  `cooldown` each tick. They go when the mirror is fed by change lists alone (step 6d).
- **The whole tick** moves within its run-to-run spread in both cases; 19 µs is about 0.4% of it.
- **No traps on production maps yet (24.3),** so play is unaffected today. The saving matters once maps place them.

## Method

- **The script.** The scratch harness 42.73 used: the 24x12 live map, seed 4217 (cached), content-7, bots, 300 ticks of
  warmup, then 600 ticks of `step` with `snapshot` under the profiler, five rounds. With `--traps` it places one trap of
  each of the four kinds, in turn, at every third ground item's spot, as 42.73 did.
- **Order.** Current, baseline, current, each plain then with traps, in sequence, under the machine bench lock. Other
  processes were 6–7% busy, below the 25% contention threshold. The baseline is a pristine export of `main` at
  `15d1ff24` with its own core build, since this stage changes `hazards.rs`.
- Machine: Ryzen 9 5900X, Windows 11, 2026-11-21.

## Limits

- **One map and one trap density.** The saving scales with the trap count: ten words a trap per call.
- **Uploads are not measured here.** The bench never replaces its list or calls `setTrap`, so it uploads once. An upload
  costs what every call cost before.
