# 42.41. Landing and evac before other set pieces (#891, retired)

Back to [42](42-performance-history.md). Current placement ordering belongs to
[51.3](51.3-placement.md). This is the historical record of the retired
landing/evac-first experiment (#891). Corey approved retirement on #928
(2026-11-09); the library field, Lab menu, probe option and dedicated tests
were removed. Hand-authored libraries stating `startEndFirst` now fail
validation as an unknown field. Bundled libraries never stated it, so their
maps, fingerprints and content versions were unchanged.

Corey suggested reserving the constrained edge pieces first after the Placement lab
showed many attempts failing before fill. The experiment placed classes with the
`start` rule first, then `end`, then all remaining pieces in the existing stable
largest-first order. It preserved the selection of pieces and their named random
stream; subsequent anchor choices and maps intentionally differed when enabled.

## Matched sample

Measured on 2026-11-08: default bundled 12 × 6 library and `chainParams()`, exactly
`sweep-1` through `sweep-30`, macro placement only. Each mode used all 30 seeds,
allowing the existing 50 attempts per seed. Counts were summed over every attempt.
Root WFC failures had one node and zero open-face refusals. Pre-assignment failures
returned before WFC begins.

| Outcome | Library default | Start/end first |
| --- | ---: | ---: |
| Attempts | 107 | 61 |
| Pre-assignment failures | 65 | 21 |
| Landing failures | 27 | 0 |
| Evac failures | 25 | 0 |
| Transit-station failures | 12 | 19 |
| Plant-works failures | 1 | 1 |
| Market-court failures | 0 | 1 |
| Root WFC failures | 12 | 10 |
| Later WFC failures | 0 | 0 |
| Seeds placed | 30 | 30 |
| Seeds exhausted | 0 | 0 |

The order eliminated the 52 landing/evac failures on this panel and used 46 fewer
attempts (43%). Other pre-assignment failures increased from 13 to 21. It moved the
packing pressure to other pieces; it was not joint packing or backtracking and did
not address the independent seam-fit gap (#856). These are failure counts, not a
timing comparison or evidence of a runtime speedup. At that checkpoint, larger sizes, sparse-side libraries, map quality and live
matches had not been measured. The #928 follow-up below covered the adopted libraries.

## Historical reproduction and adoption boundary

These commands describe the original experiment at its historical revision;
the `--start-end-first` option no longer exists and cannot reproduce it on current code.

```powershell
# Historical commands for the pre-retirement revision; not supported by current code.
node map/tools/placement-probe.mts --size 12 --prefix sweep --from 1 --to 30
node map/tools/placement-probe.mts --size 12 --prefix sweep --from 1 --to 30 --start-end-first
```

Each command printed per-seed outcomes and aggregate counts. The timing
fields were not used for these counts; timing comparisons follow [31](31-verification.md).
The original per-attempt report remains in local, ignored
`test-results/edge-priority/report.json`.

The Map Lab exposed the flag under Placement → Set-piece order. Its cloned library
and recorded metadata identified the experiment. The normal World recipe and bundled
content retained their existing order. Default adoption would have needed Corey's content-batch
decision, one version bump and the final sweep recapture under [31](31-verification.md).

## Adopted-library follow-up (#928)

At `0129edd8`, sparse / alternate bundled libraries with placed-piece fitting,
`sweep-1` through `sweep-30` at each width, default versus landing/evac-first:

| Width | Attempts | Piece failures | WFC failures | Wall seconds | CPU seconds |
| --- | --- | --- | --- | --- | --- |
| 12 | 121 -> 42 | 91 -> 11 | 0 -> 1 | 41.539 -> 42.971 | 44.765 -> 46.079 |
| 24 | 34 -> 34 | 4 -> 0 | 0 -> 4 | 202.941 -> 217.605 | 207.016 -> 222.125 |
| 36 | 33 -> 40 | 0 -> 0 | 3 -> 10 | 489.784 -> 504.641 | 496.968 -> 511.500 |

All 30 seeds placed in every panel. Runs were sequential default/enabled pairs
by size, holding the benchmark lock; these single pairs establish no confirmed
timing regression or speedup. Three structural seeds per size retained instance
counts (28, 58, 66) but changed positions broadly and piece mixes in four of nine
pairs (two of three at 12 wide, two of three at 24, none at 36). No systematic map-quality benefit was established.

Corey approved retirement: fewer cheap retries at 12 wide did not improve
completion rate or measured time, while larger sizes shifted failures into WFC.
Full per-piece counts, parameters, limits and structural evidence are in the
[findings on #928](http://192.168.1.170:3000/corey/astra_test/issues/928#issuecomment-11407).
Default bundled maps and content versions stay unchanged.
