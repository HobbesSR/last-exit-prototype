# 42.74. Door state in the Rust core (#1214 stage 6a)

Up: [42](42-performance-history.md). Design: [27](27-rust-path.md#the-state-flip), step 6a. A game's door state lives in
its gate set's masks (`rust/core/src/sight.rs`), owned through `shared/sight-core.ts` (`ownGates`) and mirrored by
`shared/simulation/doors.ts`. `characterization-physics`, its `-bots` variant and `tools/trap-continuity.mjs` passed
unchanged.

## Finding

**No call in a game writes a gate mask now. On the bench's map that saves about 3 µs a tick, about 0.06% of the tick,
inside the run-to-run spread.**

- **What went.** On `main` (`92df3a9d`), a tick wrote the 421-gate open mask 4.05 times and phase 6's lock mask 1.01
  times, counted over 600 ticks. Each write is one pass over every gate on the map, about 0.55 µs for the open mask
  (42.66). That came to about 3 µs a tick, and it grew with the map's gates rather than the active set. It was the
  last such packing (42.62's exception).
- **The labels.** In the per-label medians below, every label that wrote a mask reads the same or lower. The
  differences are a few microseconds, the size of the estimate, and comparable to label noise between runs.

| 24x12, seed 4217, median of five rounds | Current run 1 | Baseline (`92df3a9d`) | Current run 2 |
| --- | ---: | ---: | ---: |
| Whole tick with snapshot | 4.914 ms | 4.813 ms | 4.775 ms |
| `sim.sync` | 57.7 µs | 64.7 µs | 59.6 µs |
| `sim.actions` | 46.9 µs | 47.7 µs | 44.8 µs |
| `sim.pickups` | 34.2 µs | 35.7 µs | 34.2 µs |
| `sim.discovery` | 558.0 µs | 560.3 µs | 549.5 µs |
| `sim.projectiles` | 13.7 µs | 13.8 µs | 12.3 µs |

- **The whole tick** varies by about 3% between the two current runs, more than the change could move it. The
  labels that moved most between runs are the bots' (`sim.bots`: 3.47, 3.32 and 3.36 ms), which this change does
  not reach.
- **The budget.** Nothing new crosses. The between-tick command (`setDoor`) writes two bytes and is not called in play.

## Method

- **The script.** A scratch harness, as for 42.69–42.73: the 24x12 live map, seed 4217 (cached), content-7 and bots.
  Each round warms for 300 ticks, then times 600 ticks of `step` with `snapshot` under the profiler, for five rounds.
  It runs under the machine bench lock and reports other processes' busy share: 5–7%, below the 25% contention
  threshold.
- **Order.** Current, baseline, current, in sequence. The baseline is a pristine export of `main` at `92df3a9d`,
  with the same core build, since this stage changed no Rust code.
- **The count.** One extra round on the baseline, with a profiler count added where each mask was written.
- Machine: Ryzen 9 5900X, Windows 11, 2026-11-21.

## Limits

- **One map.** The saving grows with the gate count: a map with more gates saved more per write, at about 1.3 ns a
  gate (42.66).
- **The 42.58 remeasure is not this record's.** The state-flip exception ends with the whole flip (step 6e). That
  stage measures again the steps that used it.
