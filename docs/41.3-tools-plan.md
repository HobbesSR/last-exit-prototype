# 41.3. Tools plan

Up: [41](41-roadmap.md). Design: [22.8](22.8-development-tools.md). Tracker: #772.

Two tracks that can run in parallel. Each row is a
reviewable PR with its own evidence; within a track, take them in order unless a
row says it is independent.

| Order / issue | Deliverable | Done when |
| --- | --- | --- |

but not for their core work.
