## Review follow-up: shared conversion and retained replay memory (#1162)

Fixed runtime checkpoint: `15f4ed7568b9d8f7dcba410f1a2b914fdb9fb9f6`.

Reviews 892/893 found that the initial client converter copied every item/gate
for every retained frame, destroying the recording reader's unchanged-record
sharing. The join now lives in `shared/relational-frame.ts`. Projection,
discovery, replay, client, prediction and labs call that same implementation.
Numeric bodyless records pass through; posed and merged records are memoized
by source plus body, geometry or seat metadata. Server conversion and body
owner tables are cached per captured frame. Compact ground publications retain
their immutable full counterpart and spatial grid when its body pose matches.
Seat extraction and validated serialization are also cached per captured frame.
The fixture is unchanged by this behavior-preserving follow-up.

The opt-in `tools/perf/relational-replay.mjs` probe constructs a fixture-sized
recording: 3,500 frames, 920 shared items, 90 gates and 12 moving players/bodies.
Unchanged item lists and gate records/lists share identity as the reader does;
one gate changes every 50 ticks. Legacy and relational inputs express the same
poses and gate states, but their source representations differ. Both decoded
source and timeline stay explicitly rooted through final GC. Load excludes
archive parsing, decompression and drawing; heap is added timeline heap over
the already allocated decoded source. Synthetic fields are lighter than a full
recording, so these absolute numbers do not replicate review 892's exact probe.

| Timeline construction | Wall time | Added retained heap |
| --- | ---: | ---: |
| `bab39739`, legacy | 4.18 ms | 2.57 MiB |
| Original PR `376834ff`, relational | 273.31 ms | 285.89 MiB |
| Fixed shared converter, relational | 53.00 ms | 19.78 MiB |

The added records now follow changing poses and metadata, rather than every
static item times every frame. One cheap sharing test covers unchanged items,
players, posed records and gate geometry across two frames, changed-body
invalidation, and preservation of the native published ground list. It is an
identity assertion, not a timing or memory threshold in CI.

measurements, not repeated alternated pairs establishing durable performance
ratios. Short replay CPU readings have coarse Windows timer granularity.
