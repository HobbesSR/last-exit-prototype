## Boundary

Experimental P1/P2 snapshots retain private engine-free gameplay state and add
closed renderable body/tether lists. Live projection filters those lists from
the captured tick. Hidden endpoints omit the whole tether; pending effects,
motors, forces, backend settings and checkpoints stay private. The renderer uses
stored shapes/poses, independent actor aim, and current sight/concealment. It
does not initialize physics for playback. Actual body motion updates a linked
item's captured position, invalidating its item layer without mutating gameplay
during capture. Physical loot admission and its gameplay synchronization remain P5.

Schema 10 requires reader 10 only for experimental physics matches. Existing
rules/content identities and ordinary reader floors are unchanged. P4 still
owns local physics prediction and correction; this slice displays authority.

## Serialization witness

Run `node tools/physics/presentation-report.mjs docs/reports/physics-440-serialization.json`.
The [retained report](reports/physics-440-serialization.json) identifies Node,
the base commit and measured source digests. It samples 200 paced ticks with
128 moving box bodies and eight ropes, recording both display and synthetic
private gameplay state. Live payloads exclude private state. The machine-wide
benchmark lock was held, with this task's tests/browser work stopped.

| Measurement | Result |
| --- | --- |
| Layer encoding, JSON and writer append CPU | mean 0.479 ms, p95 0.595 ms, max 0.836 ms |
| Recorded frame JSON, uncompressed | 9,639,362 bytes total; 48,197 bytes/frame |
| Live layered state JSON | 4,188,678 bytes total; 20,943 bytes/frame |
| Peak uncompressed writer pending bytes | 50,719 |
| Published gzip archive | 515,107 bytes |
| Omitted frames | 0; retained-frame digest verified |

The moving body layer rekeys frequently; this witness does not claim large
delta-compression savings. Compression drains outside the timed CPU interval.
This excludes simulation, player/map payloads and production scheduling; it is
not a whole-room capacity or tail-latency qualification. Separate focused tests
exercise whole-frame omission and publication failure with body-heavy frames.

The ordinary `npm run bench` completed 2,746 ticks with mean 2.431 ms, p95
5.010 ms and no ticks above 50 ms. `npm run bench:client` entry workload rendered
721 frames over 12.02 seconds, mean frame interval 16.67 ms, mean render work
0.477 ms and mean state size 2.3 KiB. These are current legacy-default smoke
measurements, not a before/after speedup or physical-match qualification.

privacy fields/shapes, hidden endpoint omission, captured spectator delay,

## Review follow-up

PR #485 review 364 narrowed observed opponent bodies to pose/shape/lifecycle;
own correction bodies and directed/recorded values retain velocity and sleep.
Closed copies now live with the other wire contracts in `projection-contract.ts`.
The reader floor uses the match factory's pinned `hasPhysics` capability rather
than an enumerated rules-version list; a future-version header witness retains
floor 10. None of these changes alters the retained full-state serialization sample.

Interpolation matches each body by ID so unrelated untethered item appearance,
removal or reordering no longer freezes actor motion. Prop rendering tests now
cover actual shape/sight/viewport intersection, including circles and rotated
boxes whose center is hidden, with a shared radius helper. Roof concealment
still uses the center; hidden center tether anchors remain omitted even when a
prop edge is visible. The playback browser fixture exercises these distinctions.

Review 365 moved the shape sight rule into `view.ts`, beside point/actor sight.
The physics presentation helper now only adapts body geometry. Shared shape
primitives handle clipping, bounds, containment and exact circle/polygon overlap.
The frame query cheaply rejects off-camera bodies, lazily prepares the clipped
sight fan once, and shares its convex regions across the frame's props. There
are no per-body sight-boundary/viewport-boundary intersection recomputations.
