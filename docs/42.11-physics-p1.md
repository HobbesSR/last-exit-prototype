## Delivered boundary

The explicit async `createPhysicsGame` / `createPhysicsMatch` factories select
`last-exit-0.8-physics-1`; `createGame` and default room composition retain
`last-exit-0.7` with the default content (`content-3` when measured, `content-4` since #473). No client protocol selects physics.
The experimental coordinator implements the reviewed seven phases, with one
consumed input per actor, all-body movement, canonical query impacts, stable-ID
finalized attacks/interactions and capture after completion.

One match owns one Rapier 0.21.0 world. The engine-free boundary has stable body
IDs with monotonic generations, canonical mutation ordering, bounded queues,
fixed substeps, force/impulse separation, motion admission/caps, native center
ropes, contacts, gameplay snapshots and idempotent disposal. Teleport resets
velocity/motor/constraints and invalidates stale effects. Pending attachments
revalidate living endpoints, generations, range and reach at admission. Final
frames stay detached/readable after disposal; joining before tick zero reconciles
body IDs before recording. Static shapes/masks and gate footprints are pinned;
gate open/closed changes commit at the boundary. P8 owns a general shared
geometry-revision transaction.

The profile uses four 12.5 ms substeps, 40 units/metre, 24-unit speculative
distance and the remaining reviewed #472 settings. Initial unsupported body
speeds fail admission; forces, impulses and motor recovery share bounded motion
before/after each substep, including rotating prop tip motion. Generic numeric
guards reject backend-unrepresentable values without claiming support beyond
the authored live-map extents. Guards are 27 actors, 128 total dynamic bodies,
eight ropes, 1,024 queued commands and 8,192 contact facts. This is a narrower
dynamic-body guard than the P0 workload's separate actor/prop counts, not a new
capacity qualification. Fast projectiles use radius-2 geometry queries and actual
substep actor paths; no projectile also enters legacy advancement.

Schema 8 adds optional private physics gameplay state to authoritative frames.
It includes dynamic transforms/generations, motor and rope state and pending
effects. Static descriptors are derived from the recorded map, not repeated per
frame. Live projections strip this state; prediction/projection/rendering work
is still P3/P4. The adapter debug snapshot may include static descriptors. Both
are gameplay/debug state, **not exact backend checkpoints**: production exact
restore is explicitly unsupported. Existing archives remain state-only playback.
