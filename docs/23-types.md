# 23. Types

`shared/` is TypeScript. Nothing is compiled to an output directory: Node erases the types as it loads a module, and `server/shared-assets.js` does the same per request for the browser, so the client runs the same source the server does. `tsconfig.json` sets `erasableSyntaxOnly`, which is what keeps that arrangement honest — enums, namespaces and parameter properties are rejected, so every annotation really is whitespace at runtime. Erasure preserves line and column positions, so a browser stack trace still points at the real source line and there is no source map to maintain. Type checking is `npm run typecheck`, never a step between editing a file and running it.

`shared/types.ts` is the single vocabulary. The branding policy there is deliberate and asymmetric, because a brand costs a cast wherever a value is built. Identifiers are branded: they are strings that are never arithmetic, so one cast where each id is minted buys separation between every `GateId`, `ItemId` and `PlayerId` thereafter. Tile coordinates are branded because the arena has four coexisting coordinate spaces — absolute world, absolute tile, tile relative to a navigation grid's origin, and world relative to that same origin, all of which appear within a dozen lines of the bot repath — and tile arithmetic is confined to `simulation/geometry`, `map/navigation` and that one block. World coordinates and tick counts are plain named aliases: they are combined arithmetically on nearly every line, so branding them would demand a cast per expression and buy less than the named field and parameter types already do.

Closed vocabularies are literal unions rather than `string`, carried items are a discriminated union so `ammo`, `charge` and `count` cannot be read off an item that has no such field, and the generation stages are assertion signatures, so the stage order the generator depends on is checked rather than assumed. Collision and routing take the narrow map views they actually read, not the whole map, because they run during generation before the map is complete.

`erasableSyntaxOnly` and `exactOptionalPropertyTypes` are on; `noUncheckedIndexedAccess` is not. Enabling it is worthwhile and is deliberately left as separate work: this codebase indexes arrays constantly, and the change belongs in a pass that can consider each site rather than one that sprays assertions.

Conversion covered `shared/` only. `server/`, `public/` and `tests/` remain JavaScript and are not type checked; they import the shared modules by their `.ts` specifiers, which Node and the asset route both resolve.
