whole-mask connectivity checks, allocator candidates, state scoring, and nested

## Neck alley child diagnosis (#611 / #535, 2026-10-27)

The default `block` recipe `{type:'block', shape:'neck', width:36,
height:30, seed:1}` has a genuine child portal-promise failure. The final
parent passes sampled reach and the five lots (508 cells) pass partition
accounting, but the separately built empty alley child reports seven
unreachable portals, including east from west. This is stronger evidence
than the route-search miss alone recorded by #610 above.

`tests/micro-block-neck-diagnostic.test.js` retains an exact geometric
separation witness from the child's access mask, including inherited clear
context. In cell coordinates it excludes rectangles `[3,11] x [0,19]`
and `[12,24] x [20,30]`. The mask's vertical bounds are 0 through 30.
Every continuous route between the west and east portal stands crosses
`x=11.5`. Below `y=19` that line is half a cell from the first excluded
rectangle; above `y=20` it is half a cell from the second. Between those
heights the greatest possible distance to the nearer excluded corner is
`sqrt(0.5)` cells (28.284 world units at cell size 40), attained at
`y=19.5`. Even the hunter's body radius is 0.875 cells (35 units), before
its 0.05-cell clearance margin. Thus no hunter disc can cross that line.
This establishes physical separation within the child's permitted access
context independently of lattice sampling; it does not claim that the
parent's actual geometry is disconnected.

The planner's connected-cell remainder check is insufficient for this
concave-mask child promise. Parent success cannot substitute for child
success because parent routes may use lot interiors beyond explicit child
clear context. #614 owns a separately scoped, content-changing correction;
#611 only diagnoses and retains a known-defect witness. No planner,
validator, portal promise, compatibility version or generation output is
changed by this investigation. Replace the diagnostic characterization
with a passing child-reach regression when the correction lands.
