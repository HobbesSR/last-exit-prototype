## Delivered boundary and witnesses

`content-physics-2` explicitly selects `last-exit-0.8-physics-2`. Normal rooms
retain `last-exit-0.7`/`content-4`; omitted physics-factory content retains P1.
P2 pins narrower movement footprints independently of nominal head art and
existing combat queries. Floor regions scale steering, braking and target speed.
External impulses survive bounded recovery and have a separate event limit;
total speed also has a pinned limit below the adapter's geometric ceiling.

Four adapter contact cases exercise head-on and glancing contact, mixed radii,
coincident-centre stable-ID ties, a corner crowd and a doorway queue. Every
returned substep is checked for actor penetration <=0.5 and static containment.
Coincident centres are deliberately invalid initial test state: only their
finite, insertion-independent trajectory is asserted, not immediate recovery
from arbitrary overlap. Normal placement refuses or relocates those spawns.

Fourteen character integration cases exercise profiles and retained P1 identity,
unchanged projectile hit envelopes beyond the smaller bodies, immutable tuning,
surface priority and stable-ID ties, low traction/braking, slowed movement,
bounded impulse recovery and actual-path distance, speed/impulse admission,
reversed rosters, occupied gates, direct door interactions including props,
teleport/joint/velocity/generation cleanup, death, impossible spawn and deferred
respawn. A blocked transit preserves cooldown/effects; a valid landing clears
motion and constraints. Between-tick teleport markers survive the next completed
capture and then expire; an in-step placement reaches only its own capture. A door
is not closed on a same-phase transit landing, and P1 ignores motor surfaces. These are intentional new expectations, separate from
the frozen fixture.

Three opening/containment cases use actual authored geometry: both roles cross
the hut builder's 80-unit door over 16 seeds covering all four orientations;
the legacy generator's 32-unit shortcut still admits the new contestant and
blocks the new gladiator (seed 4217). Both roles at the new speed cap remain
outside a playable-mask hole at every substep, with bounded temporary static
penetration and recovery within four stopped ticks. Authored openings and
actual-path distances are checked without changing map generation or navigation.
Conservative navigation can still reject routes narrower physical actors fit;
P8 owns that later agreement.

Two descriptor cases verify optional, detached, frozen geometry and malformed
field rejection. The new isolated browser witness runs a real P2 match and
checks the three Phaser circle radii/colors, authorization, two marker scales
and hiding after returning to player view. It also runs a legacy match with the
same descriptor and confirms the overlay stays hidden. The server composition
option forwards the existing optional match factory; no client command selects
experimental physics.

Nine historical P1 scenarios and all 33 capture boundaries remain exactly equal
to the retained [P1 report](reports/physics-438-phases.json). Source hashes differ
because the implementation now includes P2; historical source provenance and
report bytes remain unchanged. Reproduce the comparison with
`node tools/physics/phase-traces.mjs test-results/physics-439-p1-traces.json` and
compare the reports' `scenarios` arrays.

frozen nav-1 bot tick/projection. Syntax checks, strict typecheck and the complete
browser gate passed, including the real P2 developer overlay. The 224-map chain
sweep had zero drift; no fixture or map-generation bytes changed. The frozen
fixture SHA-256 remains
`708222c5e226019b2d601e4574f2d83c3832ed1b0cb09827bc5e9866e83ed7c8`.

New files measured under the machine benchmark lock: contact 0.7 seconds,
character 0.8, authored openings 1.0 and presentation 0.1; all below 15 seconds.
An earlier contended suite passed 921/923, failing unchanged compound/depot
macro-size time limits at 3.074/5.218 seconds. No generator source or assertion
limits were changed. Three sequential locked repeats passed at 1.002?1.011
seconds for compound and 1.710?1.752 for depot, and the full release rerun
passed. Own browser/chain tests and another observed navigation benchmark had
overlapped that failed run. The repeated checks distinguish this timing failure
from a character-physics correctness regression; they do not resolve the user's
reported slowdown.

and chain processes finished. The default server control used seed 4217,
content-4 and 12x6, completed 2,821 ticks with p95/p99 5.067/7.368 ms, maximum
16.591 ms, and zero ticks over 50 ms. This is a legacy default control,
