# 42.1. Safe navigation graph experiment (#364)

Status: research result, 2026-10-15. Up: [42](42-performance-history.md).
Design: [22.6](22.6-hierarchical-navigation.md). No production planner changes.

## Decision

Do not adopt the uniform 24-unit graph plus every-boundary-transition hierarchy
in its current form. Continuous edge safety works, but sample fidelity and measured
query costs fail this milestone's adoption gate. This negative experiment does not
establish that hierarchical navigation in general is unsuitable.

Both authored passage witnesses are physically traversable at navigation clearance
14/25, yet 24- and 40-unit sampling disconnect them. Rebuilding the small witness
patch at spacing 6 recovers both routes. The patch is 384 by 192 units; these
measurements cover that patch, not a stitched adaptive graph or a global 6-unit
world. An automatic detector of every missed passage remains unimplemented.

The lazy hierarchy preserves every legal boundary transition. Its lengths match
unrestricted Dijkstra on the identical safe graph for every measured route and
focused differential fixture. Cold queries perform many separate chunk-local
searches to fill transfer rows. Warm queries still search endpoints and reconstruct
local witnesses. Fewer coarse expansions do not imply less total work.

## Reproduction and sample

From the repository root, run sequentially:

```powershell
node --expose-gc tools/navigation/report.mjs test-results/navigation-364-final.json
node --expose-gc tools/navigation/continuation.mjs test-results/navigation-364-continuation.json
```

Both commands acquire the machine-wide benchmark lock ([31](31-verification.md)).
No tests or other benchmarks were launched alongside the final measurement. The
lock does not exclude ordinary applications or tests in other worktrees.
Committed raw reports in `docs/reports/` retain all timings, hardware/Node details,
source revision and SHA-256 experiment-source hashes. Hashes identify the source
that was uncommitted when measured.

Each authored case runs in a fresh child process: seed 1; sizes 12x6, 24x12, 36x18;
clearances 14 and 25; spacing 24 and 40; 192-unit chunks; `content-2` roster.
Final live collision geometry is baked without gate blockers. The old planner
treats unlocked doors as openable; door changes have separate authored fixtures.
Generation geometry, gameplay RNG/IDs, content/replay versions and frozen fixtures
are unchanged.

Five fixed pairs cover spawn-to-exit, first-to-last spawn, hunter-to-exit, a local
96-unit offset and first spawn-to-station. Each compares safe fine A*, unrestricted
safe Dijkstra, lazy hierarchy, and the existing 40-unit planner with 600-unit
padding. Transfer caches are cleared before each pair and cold trial. Three
sequential fine/cold/warm timings include the first query; Dijkstra is the
correctness oracle. Every returned legacy segment and connector is swept-audited;
`unsafe-success` counts as failure. Invalid endpoints and disconnected results
are retained instead of snapping across geometry.

Lengths and reported stretch are relative to the safe sampled graph plus permitted
endpoint connectors/direct segments, not continuous-space optima. One seed and
five pairs are a bounded sample, not coverage of all authored maps or matches.

## Safety and knowledge evidence

`shared/shape.ts` owns segment-to-filled-shape distance. Circles remain analytic;
polygon/rectangle tests include containment, intersections and degenerate segments.
The research adapter indexes obstacles, closed gate footprints and missing
playable cells. Every node, neighbor edge and exact endpoint connector uses the
same continuous swept-disk predicate. Tangency is conservatively blocked within
1e-9, stricter than movement's small overlap tolerance. Geometry is never repaired.

Focused witnesses cover off-grid thin walls, diagonal corners, circle/polygon
tangencies, void holes, contestant squeezes, hunter doorways and endpoints beside
walls. A near-wall loot center is invalid for the body; a reachable interaction
stand within the existing pickup distance has clear hand reach. A window blocks
hands across it.

The adversarial wall ends at y=1560, beyond the old box ending at y=720. Both safe
planners find routes reaching y=1596; the old bounded search finds no route. Door
fixtures return complete/blocked/complete after open/closed/reopened rebakes.
**Incremental door repair and hierarchy invalidation are not implemented or
established by these timings.**

Primitive support derives conservatively from clearance-expanded bounds in
discovery cells. A confirmed query admits only allowed supports; isolated
start/beacon cells cannot form a confirmed cross-map route. The authored report
times this filtered query, not a production reveal/admission pipeline. The
hierarchy is full-knowledge only and never reaches contestants.

Empty knowledge uses a separate implicit neutral graph taking only public
dimensions, spacing and body clearance. It cannot access truth geometry, mask,
gates or regions. Hidden-map twins produce identical results, work and cache
estimates. This covers empty knowledge, not the later partial-knowledge speculative
planner or target selection.

All 11 bots deliberately request the same difficult cross-map pair in an early
round, separately for both profiles and all sizes/spacings. The naive sampled
control disables direct shortcuts. Eight rounds each allow 2000 expansions per
bot and report aggregate latency, memory, completion and exhaustion. Continuation
is deterministic; exhaustion never means unreachable. Cold and warm rounds use
fresh private searches, exposing repeated work. The companion report completes
one identical request and records total work/slices. Its eleven-bot multiplier is
deterministic expansion accounting, not an aggregate completion latency estimate.

The direct neutral free-space control completes analytically with zero private
world arrays and graph expansions. This is a speculative estimate with no confirmed
executable prefix under empty knowledge; hidden geometry does not turn it into
a factual route.

## Memory interpretation and limits

The artifact estimate is two bytes per lattice sample plus an estimated 64-byte
header, not a specified persisted format. Cache/boundary bytes count scalar
payload, excluding JS containers and geometry buckets. Private search estimates
include typed arrays and heap-entry payload, excluding object overhead. Process
heap/external/array-buffer/RSS samples and OS maximum RSS include generation and
transient allocations. Maximum RSS is per child case, not the atlas footprint;
snapshot RSS does not isolate retained navigation memory. No saved-cache load
benchmark exists because no serializer or sidecar format was introduced.

The hierarchy has no private support filter, resumable budget or incremental
barrier repair. Door costs use explicit small-fixture full rebakes. Partial reveal
tests confirm paths only; the neutral optimistic test has no observed barriers.
These limitations prohibit adoption and any acceptable-tick-budget claim.

## Revised representation recommendation

Keep discovery support and continuous clearance. Next compare an adaptive local
representation that explicitly preserves narrow physical passage witnesses, with
compact shared immutable data and bounded private query state. Refine affected
patches and verify their seams with the same predicate. Boundary compression must
preserve components and real crossings; test interval/portal representatives
against unrestricted safe search. Prefer analytic open-chunk metrics over a
transfer row for every open boundary sample.

Use analytic neutral costs before allocating sampled private state. Next measure
resumable searches against observed barriers and disconnected beacons, and bounded
incremental geometry/door invalidation. Compare discovery-cell and generation-region
coarse units with these revised representations. This evidence does not choose
either coarse unit or memory versus saved delivery for production; Corey's choice
remains on #353 as required by [22.6](22.6-hierarchical-navigation.md).

No production speedup or bot completion improvement is claimed. The rejected
representation remains reproducible research tooling for the next comparison.

## Verification

Focused navigation, shape and route checks passed (28 tests). Each new test file
takes about 0.2 seconds under `test:times`, below the fast-tier limit. `npm run
check`, `npm run typecheck` and `npm run test:all` passed (705 tests, including
the retained characterization). The chain baseline check passed all 224 maps
with no drift. Raw source hashes and the 60 fine/Dijkstra/hierarchy comparisons
were independently checked against the committed reports.

Browser/client benchmarks and production match performance comparisons were
skipped: this change adds no runtime consumer, UI, transported path or bot adoption.
The dedicated locked experiments above measure this proposed representation;
they do not claim any production match performance change.
